# طراحی ایجنت مدیریت شبکه‌های اجتماعی

## هدف
یک دستیار که حساب اینستاگرام (و در فاز بعد واتساپ بیزینس) را زیر نظر می‌گیرد، پست پیشنهاد می‌دهد و پیش‌نویس می‌کند، و هر روز گزارش را به تلگرام می‌فرستد و همان‌جا بایگانی می‌کند.

## واقع‌بینی درباره «کنترل همه برنامه‌ها»
ایجنت فقط از راه **API رسمی** به هر سرویس وصل می‌شود. هر چیزی بیرون از API رسمی (ربات‌سازی روی اپ موبایل، اسکرپ کردن، ورود با رمز عبور) هم خلاف قوانین آن سرویس‌هاست و هم ریسک بسته شدن حساب دارد. پس:

| سرویس | چه چیزی ممکن است | محدودیت |
|---|---|---|
| اینستاگرام (Graph API) | آمار حساب و پست‌ها، خواندن و پاسخ به کامنت، انتشار عکس/ریل/کاروسل | فقط حساب **Business یا Creator** متصل به یک صفحه فیسبوک. دایرکت‌ها نیاز به مجوز جداگانه و بررسی اپ دارند. استوری فقط برای حساب Business. حداکثر ~۵۰ پست در ۲۴ ساعت از طریق API. |
| واتساپ | فقط **WhatsApp Business Cloud API**: دریافت و ارسال پیام برای یک شماره بیزینس، آمار گفتگوها | **واتساپ شخصی هیچ راه رسمی برای اتوماسیون ندارد.** برای واتساپ بیزینس، پیام‌هایی که بعد از ۲۴ ساعت از آخرین پیام مشتری ارسال می‌شوند باید قالب (template) تأییدشده باشند و هزینه دارند. |
| تلگرام (Bot API) | ارسال گزارش، فایل، دستورات تعاملی | ربات فقط در چت‌هایی که با آن شروع شده‌اند پیام می‌فرستد. |
| بقیه اپ‌ها | هر سرویسی که API رسمی دارد (مثلاً یوتیوب، لینکدین، جیمیل، تقویم) قابل افزودن است | سرویس بدون API رسمی قابل اتصال نیست. |

## معماری

```
            ┌────────────────────┐
 cron ────▶ │  daily job         │──▶ Instagram Graph API (خواندن آمار، کامنت‌ها)
 (GitHub    │  agent/daily.py    │──▶ Claude (تحلیل، ایده پست، کپشن، پاسخ کامنت)
  Actions)  │                    │──▶ SQLite (اسنپ‌شات روزانه، پیش‌نویس‌ها)
            └─────────┬──────────┘
                      ▼
               Telegram Bot API ──▶ پیام خلاصه + فایل Markdown کامل (بایگانی)

            ┌────────────────────┐
 تلگرام ──▶ │  bot (long poll)   │ /report /drafts /publish /confirm /reply
            │  agent/bot.py      │──▶ Instagram Graph API (انتشار، فقط بعد از /confirm)
            └────────────────────┘
```

- `agent/instagram.py`: کلاینت Graph API. متریک‌هایی که در نسخه فعلی API پشتیبانی نمی‌شوند رد می‌شوند و کل گزارش را خراب نمی‌کنند.
- `agent/ideas.py`: یک درخواست به Claude با خروجی ساختاریافته (JSON Schema): خلاصه، نکات مثبت، هشدارها، ۳ ایده پست با کپشن آماده و هشتگ و شرح تصویر و زمان پیشنهادی، و پیشنهاد پاسخ به کامنت‌ها. مدل پیش‌فرض `claude-opus-5-5` با thinking تطبیقی و fallback سمت سرور.
- `agent/report.py`: ساخت پیام HTML تلگرام و فایل Markdown.
- `agent/storage.py`: SQLite برای مقایسه با دیروز و نگهداری پیش‌نویس‌ها.
- `agent/bot.py`: ربات تلگرام. فقط به `TELEGRAM_CHAT_ID` جواب می‌دهد.

## اصول امنیتی
- هیچ توکنی در ریپو نیست؛ همه از متغیر محیطی یا GitHub Secrets خوانده می‌شوند.
- هیچ چیزی بدون تأیید صریح شما (`/confirm`) در اینستاگرام منتشر نمی‌شود.
- پیام‌های خطا توکن را نشان نمی‌دهند و لاگ httpx (که URL شامل توکن دارد) خاموش است.

## نقشه راه
1. **MVP (این نسخه):** آمار روزانه اینستاگرام، تحلیل و ایده پست با Claude، گزارش و بایگانی در تلگرام، انتشار عکس و پاسخ کامنت با تأیید.
2. **فاز ۲ — اینستاگرام کامل‌تر:** انتشار ریل و کاروسل، زمان‌بندی خودکار پیش‌نویس‌های تأییدشده، گزارش هفتگی و ماهانه با نمودار، تحلیل رقبا با Business Discovery API.
3. **فاز ۳ — واتساپ بیزینس:** وب‌هوک Cloud API روی یک سرور کوچک، خلاصه روزانه گفتگوها در همان گزارش تلگرام، پیش‌نویس پاسخ با Claude و ارسال با تأیید.
4. **فاز ۴ — بقیه سرویس‌ها:** هر سرویسی که API رسمی دارد و شما می‌خواهید.
